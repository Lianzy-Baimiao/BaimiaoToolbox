# 小队钥石 · 1.9.13

## 展示

打开史诗钥石地下城页签，“设置 / 刷新”正下方自动显示当前小队的队友钥石，最多四行：职业色姓名、层数、副本。**没有入口，不需展开，不显示自己，不显示团队成员。** 其他元素坐标和窗口大小保持原样；当前钥石 / 评分的文字宽度会在队友存在时略收窄，以免覆盖新行。

1.9.13 将姓名列从 34 扩为 100 像素，整行向左扩展 66 像素，层数 / 副本列与右边界不动；常见六字中文名和 12 字母英文名可直接看全。当前钥石长标题按需缩字（最小 14 号），空位充足时仍为 18 号，避免与队友相互覆盖。

超长姓名和副本名仍受列宽限制，悬停可查看完整姓名-服务器、钥石和来源，提示跟随鼠标。姓名职业色来自当前小队单位，持有钥石按层数色展示，不套用“超时记录”的暗色。

## 数据边界

暴雪接口能获取本人持有钥石，不能直接读取队友背包。本功能只接收当前队友主动分享的钥石：

- 兼容插件通过 LibKeystone 的 **LibKS** 协议，或 Keystone Group List 的 **WA-KeyStGrList** 协议发送。
- 队友在小队 / 副本频道分享的 **钥石物品链接**（并非普通物品名称或成绩链接）。
- 两种方式都没有数据时显示“待同步”；对方明确发送 0/0 时显示“无钥石”，离线则显示“离线”。读取失败或受限不是“没有钥石”，不编造零值或用最佳记录代替。
- 只按当前 party1…party4 的 GUID 和完整姓名-服务器匹配。非队友、公会 / 密语消息、跨服同名但服务器不符的消息均不采用。
- 会话缓存不写入存档；离组、换 GUID、离线、过图、挑战开始 / 完成时清理。读取快照时最长采用 10 分钟内数据；超过后回到待同步（界面在下次刷新时反映）。分享值仍可能是队友插件的旧缓存，不等于即时背包检查。
- 打开页签、点击刷新、队伍改变及挑战结束时请求同步；普通请求间隔至少 5 秒，同一协议响应间隔至少 3 秒。背包事件合并变化，不重复广播未变钥石；战斗 / 聊天锁定时不发送，脱战重试。只发插件消息，不自动发送可见聊天。

## 协议说明

两个格式为独立实现，没有复制或打包第三方库 / MRT 代码。

| 前缀 | 请求 | 响应 |
| --- | --- | --- |
| LibKS | R | level,mapID,rating |
| WA-KeyStGrList | KSGL:Request:0 | KSGL:Send:mapID:level:0:0:0 |

普通小队用 PARTY，实际副本匹配队伍用 INSTANCE_CHAT；不从 GUILD 读取。某些原版 LibKeystone 只监听 PARTY / GUILD，因此在 INSTANCE_CHAT 下不能保证与所有 LibKeystone 使用者互通；同版工具箱及支持对应频道的实现才可交换，亦可由队友分享钥石链接。

格式只读参考本机 EUI_Kogotool 的 Core/Gameplay/KeystoneList.lua 与 EllesmereUI 所带 LibKeystone v11；没有读取其设置或移植库实现。地图名称仍通过游戏地图 API 获取。

## 游戏内检查

1. 已正常加载 1.9.11 / 1.9.12 可 /reload；更早版本完全退出客户端后重进（新增运行文件）。打开史诗钥石地下城页签；单人时不出现空白入口，原有窗口位置与尺寸不变。
2. 邀请四名队友，默认显示四行，自己不在其中；检查按钮、当前钥石、词缀、副本卡片及右侧记录没有移动 / 重叠。切其他页签再返回不残留或增高。
3. 使用同版工具箱、LibKeystone 或 Keystone Group List 的队友点击刷新；检查地图 / 层数及职业色。未安装兼容插件的队友先显示待同步，分享钥石链接后可显示。检查六字中文 / 12 字母英文姓名直接可见、跨服全名和超长名字悬停；开关右侧周记录后仍不重叠。
4. 队友换钥石、离组、重组、换角色、离线、进出副本后，不得沿用其他人的钥石；转为团队立即停止显示。
5. 战斗期间只更新可读取数据，不自动发送；脱战后刷新。验证普通小队及匹配副本频道，不保证所有第三方实现的频道兼容性。

离线测试覆盖真实服务代码、两种协议、跨服身份、节流、受限值、生命周期和四行布局；不能代替当前客户端及第三方插件的联网测试。
