# 白描工具箱

魔兽世界正式服小工具合集。输入 `/bm` 打开工作台，各功能可独立开关。

## 功能

- **坐标喊话**：显示坐标、移速和目标距离，支持自定义喊话模板。
- **快捷按钮**：五类坐骑在同一页设置，可自选鼠标点击组合键或不绑定；扩展内容逐条选择类型、填写名称 / ID 与可选短名，支持新增、删除和上下调序，常用动作直接从下拉列表选择。
- **光环 / 宠物提示**：提醒缺失光环或宠物，可自定义文字和样式。
- **嗜血 / 战复监控**：显示嗜血状态和战复次数，支持自选嗜血音乐。
- **循环提示助手**：按专精保存自定义技能顺序，支持空格分隔、单体 / AOE 分支标注与冷却显示，所有技能始终单行排列；每个方案可填写备注并选择显示在循环下方，附惩戒骑预设。
- **大秘境信息**：副本成绩、本周记录、宝库进度、队友钥石和副本传送。
- **小工具集合**：右键邀请与复制角色名、进本信息、排队就绪提醒、交易回执、标记助手和团队倒数。
- **拍卖行助手**：85 项预设（含公函）、彩色属性速览与分类收藏、多套补货清单、追踪配方材料补货；限价可留空，自动查价，每项点一次购买。独立深浅色面板，不依赖 Yishier。

## 安装与使用

下载 [安装包](https://github.com/Lianzy-Baimiao/BaimiaoToolbox/releases/latest)，将 `BaimiaoToolbox` 文件夹放入 `World of Warcraft\_retail_\Interface\AddOns\`，重启游戏。

输入 `/bm` 或点击小地图按钮打开设置。功能配置账号共享，位置与锁定状态按角色保存。

全局字体轮廓：打开 `/bm` → 左侧「外观设置」→「轮廓字体」。账号共享、立即生效，统一控制插件所有非设置界面文字；保留各模块字号和颜色，不改设置页、游戏原生聊天 / 菜单 / 鼠标提示及其他插件字体。首次升级沿用原坐标喊话的轮廓选择。

界面支持简体中文、繁体中文、英文、韩语，自动跟随游戏客户端；其他语言回退英文。翻译文件按语言独立保存在 `Locales/`，用户自定义文本不会随语言改写。队友钥石支持 LibKeystone、Keystone Group List、AngryKeystones 与 LibOpenRaid 兼容消息，或当前队友分享的钥石链接；不能直接读取其他玩家的背包。

拍卖行助手：`/bm` →「拍卖行助手」配置，`/bmah` 打开面板；与设置窗口互斥显示。单项限价留空 / 0 为不限价，本次预算 0 为不限总额。购买按本次点击看到的数量和预估总价授权；最终报价上涨则跳过，成功后自动查询下一项，不是无人值守购买。

「追踪补货」自动读取普通制作 / 再造的追踪配方，可选全部或单个、制作份数、材料品质偏好（默认最高，另可选 1–4 阶；按材料实际档位及原生图标显示）。合并基础材料，按精确品质 ID 扣除背包、银行可见库存与已知邮件；不保证成品五星，不代选可选材料、火花或货币。普通清单仍不计银行。两种清单均可逐项搜索，停用项只在设置中显示；助手在拍卖行右侧跟随移动并等高，挂接原生窗口以同步缩放、显隐和遮挡顺序。仅购买商品类物品。

未知邮件不再要求额外确认；真实未决订单保留在途数量，避免重复下单，不因原生拍卖购买而锁死助手。购买自动确认的验证仍以离线测试为主，客户端行为需游戏内验收；首次请用少量低价材料。

插件不附带音乐文件。排队提示音遵循游戏音量及后台声音设置。
