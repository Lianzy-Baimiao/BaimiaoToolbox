# 白描工具箱

魔兽世界正式服小工具合集。输入 `/bm` 打开工作台，各功能可独立开关。

## 功能

- **坐标喊话**：显示坐标、移速和目标距离，支持自定义喊话模板。
- **快捷按钮**：按用途召唤坐骑，快捷使用技能、物品、玩具及常用动作。
- **光环 / 宠物提示**：提醒缺失光环或宠物，可自定义文字和样式。
- **嗜血 / 战复监控**：显示嗜血状态和战复次数，支持自选嗜血音乐。
- **技能顺序**：查看惩戒骑单体与群体技能顺序。
- **大秘境信息**：副本成绩、本周记录、宝库进度、队友钥石和副本传送。
- **小工具集合**：右键公会邀请、多角色选择邀请、标记助手和团队倒数。

## 安装与使用

下载 [安装包](https://github.com/Lianzy-Baimiao/BaimiaoToolbox/releases/latest)，将 `BaimiaoToolbox` 文件夹放入 `World of Warcraft\_retail_\Interface\AddOns\`，重启游戏。

输入 `/bm` 或点击小地图按钮打开设置。功能配置账号共享，位置与锁定状态按角色保存。

队友钥石需要兼容插件同步或队友分享钥石链接；插件不附带音乐文件。
