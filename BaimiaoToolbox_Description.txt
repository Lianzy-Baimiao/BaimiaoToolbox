BaimiaoToolbox — small tools, one workspace.

A modular utility addon for World of Warcraft Retail. Keep useful shortcuts, reminders, and Mythic+ information together, and enable only the features you want.

**Interface languages:** Simplified Chinese (zhCN), Traditional Chinese (zhTW), English (enUS/enGB), and Korean (koKR). The interface follows your game client automatically; other client languages fall back to English. Each language has its own translation file. Custom names, searches, and templates are preserved.

## Everyday shortcuts

- **Coordinates and sharing:** Display coordinates, movement speed, and target distance, with customizable coordinate-sharing messages.
- **Quick buttons:** Set up five mount categories on one compact page and choose their mouse/modifier click bindings. Build an extension bar for toys, spells, items, and common actions using editable rows that you can add, delete, and reorder.
- **Character and party menus:** Copy a character's full Name-Realm with Ctrl+C, send manual guild invitations, or select a specific online Battle.net character for an invitation.

## Reminders without extra clutter

- **Instance and queue reminders:** Text-only notices show instance difficulty, loot specialization, and equipment durability, or tell you when a supported dungeon, raid, battleground, or arena queue is ready. Separate hold/fade timers and optional queue sounds are configurable.
- **Trade receipts:** A local chat summary of the partner, gold, items, and enchantment service after a confirmed successful trade. No channel spam or saved trade ledger.
- **Aura and pet reminders:** Customize prompts for missing auras or pets.
- **Bloodlust and battle resurrection:** Display available status information and battle-resurrection charges. Optional bloodlust music can use media registered by other addons or a configured sound path.
- **Spell-sequence reminders:** Save plans by specialization, show cooldown cues, and add optional notes below the icons. Single-target/AOE labels can appear together. Skill icons always stay on one line and shrink to fit if necessary; three Retribution Paladin presets are included. This is a passive reminder, not a dynamic rotation engine or automatic casting tool.

## Mythic+ and group tools

- **Mythic+ overview:** Dungeon results, weekly runs, Great Vault progress, and buttons for learned dungeon teleports. Compact summaries list multiple run levels; tooltips show the full available run history.
- **Party keystones:** Show shared keys from current party members. Supports LibKeystone, Keystone Group List, AngryKeystones, and LibOpenRaid-compatible messages, plus actual keystone links shared by party members. Availability depends on the sender's addon and supported message channel; the addon cannot inspect another player's bags.
- **Marker assistant:** Target markers, world markers, ready checks, and native group countdowns, subject to game permissions.

## Auction House companion

- **Quick search:** 85 built-in presets across 11 visible categories, including profession missives, plus your own favorites. Search by name, item link, or item ID. Localized, color-coded stat labels help identify flasks, potions, gems, enchants, and missives.
- **Restock lists:** Save multiple plans with target quantities, optional per-item price caps, and a session budget. Disabled entries stay out of the shopping list; each row has a search button for checking the item in Blizzard's Auction House.
- **Tracked recipes:** Build a shopping list from tracked crafting and recrafting recipes. Choose all recipes or one recipe, crafting count, and material quality. Defaults to the highest available material quality; lower preferences use the material's actual tiers. Shared materials are combined and matching-quality bag/bank inventory and known incoming mail are counted. Optional reagents, sparks, currencies, and finished-item quality are not selected or guaranteed.
- **Click-to-buy, not unattended automation:** The helper looks up prices automatically, but each item requires a purchase click. Confirmation proceeds only if the final quote does not exceed the quantity/amount authorized by that click; the next item is then queried, not automatically purchased. Only commodity purchases are supported. Leaving a price cap or budget at zero means no configured cap. Game restrictions still apply.
- **Integrated panel:** Open with **/bmah**, or configure through **/bm → Auction companion**. The companion attaches to Blizzard's Auction House and follows its movement, height, scale, visibility, and stacking order as part of the same window hierarchy. Settings and the companion do not overlap. No Yishier dependency.
- **Readable help:** Long explanations use short lines and word wrapping. Material-quality help is concise; restock search buttons have no extra hover text.

## Make it yours

Open the workspace with **/bm** or the minimap button. Modules can be switched on or off individually, and the workspace has light and dark themes. The light theme uses neutral gray/white surfaces, darker text without black outlines or shadows, and theme-aware borders and status colors. A separate appearance page controls font outlines for the addon's non-settings text without changing Blizzard UI or other addons.

Feature settings are account-wide; frame positions and lock settings are saved per character.

## Install and upgrade

Install the addon for your **Retail** game instance. For manual installation, place the **BaimiaoToolbox** folder in `World of Warcraft/_retail_/Interface/AddOns/`, with `BaimiaoToolbox.toc` directly inside it.

When upgrading to **1.9.18**, fully exit the game before installation and restart it afterward to load the new diagnostic file. Keep your SavedVariables; no settings reset is required.

## Compatibility and limits

- Retail only, not Classic or Classic Era. Use the supported game versions listed on the download page.
- No external addon is required. LibSharedMedia-3.0 integration is optional and is not bundled. A private, modified LibDeflate component is included for party-keystone messages and does not register as a shared library.
- Missing or API-restricted information is not fabricated. An unknown party keystone does not mean the player has no key.
- Protected actions, combat restrictions, and group permissions still apply. Queue invitations are not accepted automatically.
- Queue sounds respect the game's sound, volume, and background-audio settings; they cannot force playback through mute. No audio files are included. Optional music requires your own sound source.

## 中文说明

**白描工具箱：把常用的小功能，收进一个工作台。**

面向魔兽世界正式服的模块化小工具合集，将快捷操作、屏幕提醒和大秘境信息集中管理；按需启用，不必打开所有功能。

**界面语言：**支持简体中文（zhCN）、繁体中文（zhTW）、英文（enUS/enGB）、韩语（koKR），自动跟随游戏客户端；其他客户端语言回退英文。每种语言使用独立翻译文件，自定义方案名、搜索词和模板原样保留。

### 日常快捷操作

- **坐标喊话：**显示坐标、移动速度和目标距离，支持自定义坐标分享消息。
- **快捷按钮：**五类坐骑集中在同一页，自选鼠标与修饰键组合；技能、物品、玩具和常用动作采用逐条编辑，支持新增、删除和上下调序。
- **角色与队伍菜单：**手动 Ctrl+C 复制完整“名字-服务器”，发送公会邀请，或在战网好友多角色在线时选择指定角色邀请。

### 简洁的屏幕提醒

- **进本与排队提醒：**纯文字显示副本难度、拾取专精和装备耐久，或提醒地下城、团队查找器及战场、竞技场队列已就绪；分别设置停留与渐隐时间，可选排队提示音。
- **交易回执：**交易成功后，仅在本机聊天框显示对象、金币、物品及附魔服务摘要，不刷频道、不建立交易账本。
- **光环 / 宠物提示：**提醒缺失光环或宠物，支持自定义提示。
- **嗜血 / 战复监控：**显示可获取的状态信息和战复次数；嗜血音乐可选用其他插件注册的媒体或自行配置的音频路径。
- **循环提示助手：**按专精保存方案、显示冷却，可在技能下方显示方案备注；支持单体 / AOE 同时标注，技能图标始终单行，过长自动缩小。附带三套惩戒骑预设，仅作被动顺序提醒，不是动态输出推荐，也不会自动施法。

### 大秘境与团队工具

- **大秘境看板：**副本成绩、本周记录、宏伟宝库进度，以及已学会的副本传送入口。汇总紧凑列出多次通关层数，悬停查看全部可获取记录。
- **队友钥石：**展示当前小队成员分享的钥石，支持 LibKeystone、Keystone Group List、AngryKeystones 与 LibOpenRaid 兼容消息，以及队友发送的真实钥石链接。是否能获取取决于对方插件和消息频道，不会直接读取其他玩家的背包。
- **标记助手：**目标标记、地面标记、就位确认和原生团队倒数，遵守游戏权限限制。

### 拍卖行助手

- **快捷搜索：**85 项内置预设、11 个直接可见的分类，包含公函；个人收藏独立管理，支持名称、链接和物品 ID 搜索。合剂、药水、宝石、附魔与公函显示彩色属性简写。
- **清单补货：**多套方案、目标库存、可选单项限价和本次预算。停用项目不占购买列表，每项都有搜索按钮，方便在原生拍卖行查看。
- **追踪补货：**读取普通制作及再造的追踪配方，可选全部或单个配方、制作份数和材料品质，默认材料实际最高品质。合并相同材料，按所选品质扣除背包、银行可见库存与已知邮件；不代选可选材料、火花和货币，不保证成品品质。普通清单不计银行。
- **每项点一次购买，不是无人值守：**自动查询价格；点击购买后，最终报价不高于本次授权金额才确认，成功后只查询下一项，不自动开始下一笔付款。仅支持商品类物品，限价 / 预算留空或 0 为不限，仍遵守游戏限制。
- **贴合原生窗口：**输入 **/bmah** 打开，或通过 **/bm → 拍卖行助手** 设置。助手挂接到原生拍卖行的同一窗口层级体系，跟随移动、高度、缩放、显隐与前后遮挡顺序；打开设置时隐藏助手，避免交叉显示。不依赖 Yishier。
- **简洁提示：**较长的说明分行并自动折行，材料品质提示保持简短，补货搜索按钮不再附加鼠标说明。

### 按自己的习惯设置

输入 **/bm** 或点击小地图按钮打开工作台，各模块可独立开关，提供深浅两种主题。浅色主题使用中性灰白背景、深色文字，去除面板文字的黑色描边和阴影，边框与状态颜色随主题调整。独立的外观设置统一控制插件非设置界面的轮廓字体，不影响游戏原生界面或其他插件。

功能配置账号共享，界面位置与锁定状态按角色保存。

### 安装与升级

请安装到**正式服**客户端。手动安装时，将 **BaimiaoToolbox** 文件夹放入 `World of Warcraft/_retail_/Interface/AddOns/`，确保 `BaimiaoToolbox.toc` 直接位于该文件夹内。

升级到 **1.9.18** 时，请完全退出游戏后安装，再重新进入，以加载新增诊断文件。保留 SavedVariables，无需清空或重置设置。

### 兼容性与限制

- 仅面向正式服，不支持怀旧服；具体游戏版本以下载页面标记为准。
- 无需必装的外部插件。LibSharedMedia-3.0 为可选集成，未内嵌该库；队友钥石通信使用内嵌的私有修改版 LibDeflate，不注册为共享库。
- 不伪造未获取或被 API 限制的数据；“待同步”不代表队友没有钥石。
- 受保护操作、战斗限制和队伍权限仍然有效；不会自动接受队列邀请。
- 排队提示音遵循游戏声音、音量与后台声音设置，不能强制突破静音。安装包不含音频文件，可选音乐需自行配置来源。

## 1.9.18 — Settings and resource usage / 设置与资源占用

Settings pages now load on demand, with reorganized groups and clearer save behavior. Auction item-data updates are coalesced and filtered to reduce unnecessary rebuilds. Background refreshes reduce redundant work without a promised fixed CPU or memory target.

设置页改为按需创建，重新整理分组与保存提示。拍卖行物品数据更新合并处理并过滤无关事件，减少不必要的界面重建；后台刷新减少重复工作，不承诺固定 CPU 降幅或内存上限。

**Optional diagnostics / 可选诊断:** Run /bmperf out of combat for a 30-second sample; /bmperf cancel stops it. It reports native recent metrics and selected callbacks, not complete per-module CPU usage. Profiling is opt-in and results are not persisted. 脱战时运行 /bmperf 采样 30 秒，/bmperf cancel 取消；仅覆盖部分回调，不是完整模块 CPU 排行，诊断结果不写入存档。
